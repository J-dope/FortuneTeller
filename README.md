# FortuneTeller - Mobile Application (React Native / Expo)

This repository contains the practical lab assignment developed using **React Native**, **Expo**, and **VS Code** for the Mobile Application Development course.

## 📱 About the Project
**FortuneTeller** is a simple multi-screen mobile application built with file-based routing using `expo-router`. It features a welcoming home screen that prompts users to discover their coding destiny, and a second screen that reveals a fun, randomized programming fortune.

## 🛠️ Built With
* **React Native** - Framework for building native apps using React
* **Expo (SDK 57)** - Platform for making universal React applications
* **Expo Router** - File-based routing for React Native
* **VS Code** - Integrated Development Environment (IDE)

## 📂 Project Structure
* `app/_layout.tsx` - Root stack navigator configuration for the screens.
* `app/index.tsx` - Home screen of the app with an introduction image and navigation button.
* `app/reveal.tsx` - The second screen displaying the custom fortune message.
